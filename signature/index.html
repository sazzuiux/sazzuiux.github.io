  1. Click Copy signature.
  2. Open Gmail → ⚙️ Settings → See all settings → General → Signature → Create new.
  3. Click inside the signature box and press Ctrl+V (Mac: Cmd+V).
  4. Under “Signature defaults”, pick it for new emails and replies, then Save Changes at the bottom.
